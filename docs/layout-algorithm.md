# 分镜布局约束与验证

## 目标与优先级

阅读顺序 → 文字完整可读 → 画格不相交与安全间距 → 图像面积 → 斜边变化。文档顺序不变。不会为保留异形而隐藏摘要、缩小到不可读字号，或让可点击画格互相覆盖。

## 几何算法

`geometry.js` 从容器矩形开始，用同一条直线的两个半平面递归切分凸多边形。相邻画格来自同一切分，不能分别随机移动。随后每格沿所有边的法线内缩 gap/2；gap 为容器宽度的 1.6%，限制在 12–20 CSS px。共享边两侧的距离因此至少为 gap。

随机参数使用固定种子生成，`data-layout-seed` 可配置同一期的构图。主次比例和斜率均有限制；斜率还受到容器宽高比约束，避免画格增高时收缩成尖窄条。窗口变化只按尺寸重算，种子不随每帧或每次渲染改变。

## 文字安全区域

先将画格进一步内缩 14–24px，再在内多边形中枚举水平矩形候选，选择面积最大的候选。每个候选四角都在凸多边形内部，因此整个矩形都在内部。标题、摘要、分类、日期和按钮都在这一区域的真实 HTML 中排版。

实际测量字体加载后的内容高度。标签占上方空间，旁白框占下方空间；两者高度与间距一起计入约束。若容纳不下，增加所在分镜组的高度并重算，共享边仍由同一切分得到。有限轮调整仍不满足时，降级为按内容增高的全宽矩形。内容不截断，中英文连续长词允许换行；字号有可读下限，不通过字体无限缩小解决溢出。

## 响应式与重算

`layout.js` 以实际容器宽度选择横向或纵向切分。主区域宽度不足 620px 时重新组织首屏；辅助区域不足 420px 时也改为纵向。文章区域按分页结果选取最多六篇，使用当前页对应的共享切分树；窄屏改为保持文档顺序的纵向分镜。

ResizeObserver 监听容器宽度和内容尺寸；字体加载、文本修改、分类筛选和种子修改也会触发重算。所有触发通过 requestAnimationFrame 合并。观察容器时忽略自行写入的高度变化，避免反馈循环。移动端和长内容允许页面自然加长，而不强迫内容塞入一屏。

图片与墨线使用同一几何形状（图片额外内缩 2px）；链接本体使用同一 clip-path，点击范围不会延伸进裁掉的区域。主画格不做位移型悬停动画。无 JavaScript 时保留普通文档流布局。上一版没有安全区计算的跨格文字与拟声词装饰已隐藏；后续跨格素材必须使用独立保留区域与同样的碰撞验证。

## 验证与实际覆盖

- `npm test`：既有筛选、搜索、四篇文章、阅读模式、图片与减少动效回归，生成审阅截图。
- `npm run test:layout`：25 档宽度（280–2560px，包含断点附近），多个固定种子，同一页面反复缩放，分类重排，长中文标题、连续英文摘要及 200% 文字。
- 几何测试使用独立实现的分离轴检测、点到线段距离和点在多边形内检测，检查真实渲染位置；验证不相交、至少 12px 间距、文字框完整位于画格内、标签与正文框不重叠及无页面横向溢出。

这些是当前 Chromium 自动化验证范围；尚未声称已覆盖所有浏览器、系统字体或设备。后续新增素材破框、组件或字体时，应补充相应几何与浏览器验证。


## 分页结构与切换

`archive.js` 先过滤分类，再按每页六篇切片；`page-layouts.js` 维护六套二叉切分树。叶子代表画格，内部节点代表水平或纵向共享边界。末页文章不足六篇时剪除多余叶子并合并单支节点，避免留下空格或索引越界。

模板按页码循环选择；分类、页码和全局种子共同确定有界的斜率变化。每次重新进入同一页得到稳定构图。递归切分仍使用现有内缩和文字测量流程，不用负边距或任意坐标拼接。模板图可通过 `node scripts/template-diagram.mjs` 重新生成。

默认目录为四篇样刊，演示开关才追加一百篇排版样稿。目录排序稳定；可见 DOM 仅保留当前页画格，离开页面的文字元素会从 ResizeObserver 中注销。离屏预排版时额外创建一组最多六格的临时测量节点，测量结束后销毁。搜索读取整个当前目录，不限于可见页或当前分类。示例文章打开后返回目录会恢复来源状态。

切换顺序为：记录最新目标 → 取消过期动画 → 旧页整体淡出 → 替换节点并完成安全布局 → 新页逐格显影。新旧两代画格不会同时占据场景，动效仅改变透明度，不插值多边形顶点或使画格穿越彼此。减少动态效果时立即替换；动画中切换系统偏好也会取消动效。切换期间将画格设为 inert，避免误入旧内容；页码操作完成后焦点移至页状态。

状态同步到 URL，支持直接链接、刷新、历史导航、跳页、页码越界归一化和分类切换后的页码重置。快速连续翻页采用最新目标优先，旧请求不会覆盖新的页面。

新增分页浏览器测试验证：104 条唯一记录遍历 18 页无重复和遗漏；六套模板在 320、390、768、1440px 屏宽下的几何安全；不足六篇的末页；长标题、长英文摘要、放大文字；切换过程、快速操作、动画中断及减少动态效果。已额外验证构建产物在项目子路径下的分页、详情和返回流程。


## 桌面端共享画布预算

桌面端（文章容器宽度至少 620px）在显示页面前，枚举整个目录及每个分类的分页，用同一组件渲染器在离屏容器中测量文字和分镜。计算各页所需高度后取共同预算，再按共同高度复核所有页。实际显示的所有模板都从这个预算开始布局，因此六套结构、末页及分类切换不会各自改变页码区域的位置。

缓存键包括容器宽度、目录内容、全局种子及当前字体参数。字体加载完成会使缓存失效；宽度、字号或数据变化会重新预排版。运行时直接编辑的文字如需更多空间，只提高同一预算，翻页时不缩回原高度。手机端继续按内容排版，以免一页只有两篇时仍保留六篇的长画布。

预排版使用 `article-card.js` 中与真实页面完全相同的组件，临时节点不参与页面流、焦点或辅助技术，且测量后销毁。原有安全区、内缩间距及完整文字约束继续生效。

## 示意图断点回归

旧生成器将缩略图宽度 280px 当作布局输入，导致六套模板全部走入手机的纵向重排分支。修正版明确区分“布局视口”与“绘制缩放”：桌面先按 1224px、手机先按 350px 计算，再等比缩小。输出桌面、手机和并排对照三份 SVG。

生成器加入断言：每套桌面模板必须包含非通栏分镜；手机模板必须保持可读的通栏纵向结构。新增高度测试还会验证 SVG 的实际模式与布局宽度，并生成 PNG 审阅图。

验证结果：768、1024、1440、1920px 浏览器宽度下的全部 18 页画布与分页相对位置保持一致，覆盖分类切换、刷新、末页和字体放大；既有 25 档屏宽、碰撞、长文本及动态翻页测试继续通过。
