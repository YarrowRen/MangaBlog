# 首轮美术与后续 Imagen 制作规范

基调：暖白纸面 #F3F0E7、近黑墨线 #20211F、珊瑚红 #E95D50。原创成年编辑角色，黑色短发、红色发夹、圆眼镜、浅色衬衫与深色背心。黑白线稿、网点阴影，有限红色点缀。所有画面不含文字、Logo、气泡；文字用前端实现。

首轮四格概念素材：

- HOME-001：编辑室夜景。人物在右中部，左上留标题空间；桌面横版与手机竖版分别制作。
- GUIDE-001：编辑举起铅笔打招呼，近景，左上留气泡空间。
- LIFE-001：书店街角、自行车、红色遮阳棚，横版与竖版分别构图。
- TECH-001：键盘、咖啡、画稿、绘画的手，局部特写。

正式生产前先锁定角色三视图、服装、表情、线条粗细、网点密度及主场景，再逐格生成。独立审核人物一致性、手部、裁切安全区、文字对比度。首轮采用一张四格概念图集，不能作为后续逐格精修已完成的证据。

下一轮工程：Astro/MDX 内容模型、独立文章元信息与封面、RSS/归档/标签、社交分享图、响应式图片、原创角色透明图层与跨格动效。当前不以未实现的菜单入口占位。

## 第二轮：异形漫画页构图

首页首屏采用斜切主画格、梯形人物特写和斜边导读格；跨格气泡独立于画格裁切层。文章标题及摘要改为画面内旁白框，保留可选择的水平文字。手机改为纵向共享斜边构图，筛选后的文章恢复独立整格，避免空缺分镜。画格自身使用多边形裁切，裁切区不捕获链接点击。

本轮仍复用已批准方向的概念图集；未生成角色透明层，因此只有气泡跨格，人物破框留待独立人物素材制作后完成。长文阅读布局保留。

## 第三轮：共享切分与安全区

异形画格改由 `geometry.js` 与 `layout.js` 统一生成，移除负边距和独立百分比拼接。上一轮跨格气泡及拟声词暂时隐藏；后续恢复时须先为跨格层分配独立安全区，再进行碰撞检测。当前文字按实际排版测量，自动增高并在窄屏重排，完整算法和验证范围见 `layout-algorithm.md`。
