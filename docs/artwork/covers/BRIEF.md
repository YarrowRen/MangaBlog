# 前六篇文章 · 黑白漫画封面

统一参考《出包王女》的细腻墨线、鲜明表情与网点表现，使用原创成年研究员角色：短白发、黑色发饰、衬衫与深色马甲。每幅独立生成，主场景配两个细节分镜；不把文章标题烘焙进图片，真实标题继续由 HTML 排版。

| 文章 | 叙事画面 |
|---|---|
| Memory / AutoDream 演示 PPT | 研究员展示三层档案架，辅以索引笔记与梦中整理卡片的机器人 |
| KAIROS 永久助理 | 夜间工作室、时钟、工作日志、通知纸飞机与持续工作的助手 |
| Memory 系统 | 分层记忆图书馆、索引抽屉与正在被检索的卡片 |
| AutoDream | 研究员入睡，梦中的小机器人将零散记录归档为长期记忆 |
| JLPT-N5 | 日语学习桌、词典、语法卡片、笔记与活用示意 |
| WeChat / iLink | 手机与 AI 终端之间由消息、连接器和回复组成的桥梁 |

## 原图与交付

本目录保留未经裁切、缩放或扭曲的生成 PNG 原图。`assets/covers/` 保存同尺寸的 WebP 网页版本；`scripts/prepare-covers.py` 仅作格式编码并记录真实尺寸，不改变画面比例。`content/covers.js` 独立管理封面与裁切焦点，不改动文章原文。

## 页面填充

- 封面使用原生 `<img>`，常规画格以 `object-fit: cover` 等比裁切。
- 首页画格按焦点等比满幅裁切，完整漫画页在文章页与封面集中展示。
- 图片与旁白分别占用预留区，避免标题摘要压住人物；网页统一灰度呈现。
- 在文章页按原始宽高比展示完整封面，阅读模式可以隐藏装饰封面。
- 旧四格图集也改用统一比例缩放，再计算图集偏移，避免横纵两轴被独立缩放。
- `/covers.html` 提供六张完整封面的审阅集。

## 验证

`npm run test:covers` 检查原图与网页图片尺寸一致、六档屏宽、原生图片填充、旧图集统一缩放、画格几何安全及文章页封面比例。
